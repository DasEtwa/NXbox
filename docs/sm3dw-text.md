# Super Mario 3D World selection text investigation

The candidate fixes primitive restart in indexed point, line and triangle lists. The pinned driver
sends their fixed restart markers directly to D3D12 strip-cut, which implements strip restart
([D3D12 contract](https://learn.microsoft.com/en-us/windows/win32/api/d3d12/ne-d3d12-d3d12_index_buffer_strip_cut_value)).
The patch routes these lists through Mesa's existing converter and removes lists from that
converter's supported restart mask. It preserves strip, adjacency and patch draw routing. This is a
concrete contract defect; the supplied logs do not identify the missing glyph draws, so its effect
on this scene requires an Xbox comparison.

Evidence inspected: `/tmp/smtext/sm3dw_cor1.png`, `eden.txt`, `diag.txt` and `diag_swizzle.txt`.
`diag.txt:53` reports 24 PSOs created and zero failures. That excludes recorded PSO creation
failures, but does not exclude GL link/validation failures or valid draws producing no fragments.
SRV component mapping is excluded by the supplied swizzle experiment.

## Next Xbox run

Set `NXBOX_DRAW_DIAG=1` and `NXBOX_FRAME_DUMP=1` in `LocalState\nxbox_env.txt`, restart and
reproduce the selection screen. Each successful swap logs one `D3D12_DRAW_DIAG` line. Counts reset
at Mesa's presentation boundary, across contexts in the process; concurrent compilation can land in
the following interval. Startup capability probes can legitimately fail to link.

`calls = issued + skipped + forwarded` for driver invocations. Forwarded multi-draw/conversion
parents are separate from child invocations. `gl_skipped` covers GL validation/no-op exits;
`aux_skipped` covers failed primitive/vertex conversion. These counts include intentional zero-count
and culled draws. `issued` records command emission attempts; GPU predication, rasterizer discard,
sample masking, clipping, and later batch/PSO failures need their state counters and existing batch
reports. A zero `skipped` count does not establish visible pixels.

State counters cover logic ops, dual-source blend, constant/independent blend, A2C/sample mask,
stencil, enabled clip planes, point/sprite paths, restart, instancing, GS/SO, viewport/scissor,
depth clamp/bounds, predication and discard. `viewport_swizzle` observes nonidentity guest
transforms with nonzero scale. The retained `*_SKIP_LAST` values identify generated source exit
sites; `GL_LINK_FAIL_LAST` retains program ID and bounded linker text.

Host checks execute the generated restart predicate and upstream restart scanner, frame
accounting/gating/reset, generated state observer, and full patch-chain integration. They do not
compile the Xbox DLLs or establish the visual result. `/tmp/mesa-pin` is never patched.
